# 爱乐之城 · 五流派音符验证器

2026-09-27 候选 V0.3。用于试玩本轮设计，不代表正式配置或强度定稿。

## 开始测试

默认进入自由验证：45件全解锁到仓库，体力999，跳过表演过程。顶部“载入参考布局”选择五套27格构筑，或五套49格混合示例，即可表演。参考布局来自设计窗口的结构验证，只保证固定朝向下能放入，不保证最优收益。

可以拖放、点击格子、Ctrl点击自动放入/回仓、整体卸下、撤销重做。所有位置展示占格小图；绿勾表示已经放入背包。指定开放格数为测试工具，缩小区域会把越界道具退回仓库。

道具详情可逐级切换、修改六级基础值与六级技能参数。表演结果含来源音符数、品质分布、音符分、效果应用次数、高潮/Solo事件及每秒累计值。“表演日志”可再次查看明细和导出CSV。默认跳过表演；取消勾选可查看时间轴回放，支持暂停、2倍速、跳过和取消。

参数与规则可改种子、剩余体力、时长、音符除数、高潮阈值、抽奖品质方式。批量模拟支持1/100/1000场，不消耗体力。相同参数、摆放、等级及完整种子得到相同结果；单场种子带场次编号。

## V0.3机制更新

每派6件主要乐器，另10绿通用乐器、5蓝通用连接乐谱；民谣吉他改为尼龙吉他。五轮流水线取代旧逐来源结算：基础生成→基础转品→追加与复制→追加转品→计分。蓝色B01～B05已归入各派，旧49格组合仅保留为混合示例，不宣称双流派完整构筑。

结果展示存活基础/追加、四分/八分和消耗原音符数。八分基础仍属于基础；消耗的旧音符不计分，交换新音符只记一次。

### 结算批次

同一到点时刻的全部基础音符组成一批。第一轮形成快照；次数与品质检定使用词条指定的快照。各批按时间排序，来源按ID及批内序号排序。

### 类型与品质

四分/八分为玩法类型；绿蓝紫金红为品质；基础/复制/伴奏为生成方式。八分不自动算追加。默认每0.5秒产生占格数枚随机品质四分音符。

### 品质概率

绿色乐器：绿80%、蓝15%、紫5%；蓝色：蓝80%、紫15%、金5%；紫色：紫80%、金15%、红5%；金色：金80%、红20%。明文修改模版的乐器按其描述。

### 基础分与系数

绿蓝紫金红基础分为1/1.4/2/2.8/4；四分系数1，八分系数0.75。电贝斯65%专属基础系数额外乘算；复制再乘手风琴X%，不继承已结算的得分增益。

### 转换竞争

同一基础音符第二轮只被一种转换占用，依次为中音萨克斯→次中音萨克斯→黑管→鎏金竖琴→沙龙钢琴。资格读第一轮快照，实际选取只用未占用目标，概率失败也占用。

### 数量交换

两蓝换紫、两紫换金，第二轮每批最多2组、优先紫组，再按来源ID和批内序号配对。两枚原音符被消耗，只有新音符进入后续轮次。继承来源ID靠前者的类别、位置与基础系数，标记稳定升品与竖琴交换。

### 复制与标记

复制仅读取第二轮结束后存活的低品质基础四分音符。继承来源、类型、品质、随机升降与升品标记，原音符已有百分比/固定得分加成不烘焙进基础分。复制不新触发变调事件。

### 事件边界

爵士伴奏只读取第二轮成功改变品质的随机变调事件，每个存活原音符一次；概率升品、数量交换及第四轮转换不触发该伴奏。红升/绿降保持边界，不算实际变化。

### 随机解释

中音萨克斯：每次50%升1级、50%降1级，不设额外不变分支。红升/绿降停在边界，因此可能未实际变色。次中音萨克斯自身条目的X%为独立触发条件，触发后的升降方向仍各50%，不与“50%转变”的含义混用。

### 计分

音符基础分×各基础系数×(1+适用百分比之和)+适用固定加分。复制在自己的第五轮重算适用加成；合并音符继承一个来源，不叠加两份来源增益。

### 摇滚计数

仅非高潮非Solo时，按第三轮结束、转换消耗后的实际四分音符枚数累计。两紫换金计1枚，不先计2枚再补1枚。第四轮改品质不改数量。

### 高潮

达250后在下一到点批次开始前生效；弦乐与打击间隔减半，生成八分，保留专属数量/品质/基础系数。高潮暂停新积累，余数保留。时长结束恢复原模版，计时进度按比例保留。

### Solo与重合

t=5先完成该时刻已到点批次，再进入Solo。Solo在5.25/5.5/5.75/6秒各出音一次，之后恢复其他声源。高潮已生效则计时继续，Solo覆盖其出音规则；已排队且遇Solo的高潮延后至Solo结束启动。

### 上限窗口

每秒伴奏上限按(0,1]、(1,2]…统计，到边界先处理该时刻完整五轮，再开启新窗口。t=10完成到点结算后结束，无新增超时批次。

### 开场与相邻

布局属性以开场背包为准，基础属性百分比相加，乐谱基础为0。相邻指正交边接触，同件只计一次，类别统计排除乐谱。G排除空格、未解锁格与乐谱。

### 角色与单位

归属流派和核心/特色/连接是设计标识，不自动触发套装。X为本件成长参数；K、G按各条定义。数值列的百分比填6表示6%。

### 配额与通用池

每派1金核心、1紫特色、1紫连接、3蓝连接，共6件。绿通用10件、蓝通用乐谱5件独立计数，不另加共享连接池。乐谱归属通用池、定位为连接，不绑定主流派；实际收益仍取决于目标音符或属性。


## 数据与维护

- `data.json`：唯一发布数值源头，45件`base`和`effect`各6个值；`rules`为概率、时间及资源规则，`presets`为参考坐标。
- `data.js`：供无构建静态页面加载，由同步脚本生成。
- `爱乐之城-五流派数值配置.xlsx`：可在页面导入的六级数值表；参数以JSON值编辑。旧31件和V0.1 Excel不兼容，V0.3模板含版本页。
- `note-engine.js`：45件效果与事件时钟；`core.js`：复用的摆放、解锁、资源与种子基础工具。
- `app.js` / `styles.css` / `index.html`：交互与展示。
- `verify.cjs`：机制、边界、可复现与资源回归。

修改`data.json`后运行：

```sh
node scripts/sync-data.cjs
node verify.cjs
node verify-unlock.cjs
python -m http.server 4197 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4197/`。页面改值保存在本机，优先于新下载的默认配置；更新版本后，可导入新数值Excel覆盖旧本机配置。存档导出包含参数和布局；发布团队改值时，先把存档中的data保存为data.json，再执行同步与验证。修改机制必须一起修改测试；不得只改描述。

同一ID的旧31件含义不同，本版拒绝旧配置，不迁移旧存档。V0.3改用独立存储，V0.1旧存档仍保留在浏览器中，不会覆盖新道具参数。localStorage使用独立`music-notes-v03-*`前缀。

本项目纯静态，无登录账号、密钥或服务器依赖。任何成员可复制到自己的Git仓库并以根目录开启GitHub Pages，也可部署到其他静态托管。不要提交原始策划总表、账号凭据、本机存档或测试截图。

## 随机扩格更新

达到扩格消耗门槛立即自动解锁。逐格从所有合法的上下左右相邻未开放格中等概率抽取，开启后重新计算候选集合，直到本次额度用完或49格全开。随机扩格使用独立的种子序列，不干扰抽奖与表演随机序列。

初始为中央2行×3列（6格）。已有存档保留当前开放区域；旧版未使用扩格额度会在加载时自动随机兑现。新开或重置模式才使用新的初始6格。自由验证保留标明“测试格数”的调试入口，成长体验没有选格入口。

初始区域方向已更正为2行3列。尚未开始且道具可适配新区域的旧6格开局，刷新后自动更正；已有扩格进度保留，可重置测试新开局。
