# 爱乐之城 · 五流派音符验证器

2026-09-27 候选 V0.1。用于试玩本轮设计，不代表正式配置或强度定稿。

## 开始测试

默认进入自由验证：45件全解锁到仓库，体力999，跳过表演过程。顶部“载入参考布局”选择五套27格构筑，或五套49格主副构筑，即可表演。参考布局来自设计窗口的结构验证，只保证固定朝向下能放入，不保证最优收益。

可以拖放、点击格子、Ctrl点击自动放入/回仓、整体卸下、撤销重做。所有位置展示占格小图；绿勾表示已经放入背包。指定开放格数为测试工具，缩小区域会把越界道具退回仓库。

道具详情可逐级切换、修改六级基础值与六级技能参数。表演结果含来源音符数、品质分布、音符分、效果应用次数、高潮/Solo事件及每秒累计值。“表演日志”可再次查看明细和导出CSV。默认跳过表演；取消勾选可查看时间轴回放，支持暂停、2倍速、跳过和取消。

参数与规则可改种子、剩余体力、时长、音符除数、高潮阈值、抽奖品质方式。批量模拟支持1/100/1000场，不消耗体力。相同参数、摆放、等级及完整种子得到相同结果；单场种子带场次编号。

## 时间与结算边界

- t=0不产音，t=10先处理到点事件再结束。每秒窗口为[0,1]、(1,2]等。
- 同时刻常规事件按来源ID排序；每个来源批内按音符顺序。所有本时刻事件完成后才开启高潮，超阈值余数保留。高潮期间不累计下一次。
- t=5的常规批次完成后开始Solo；5.5与6秒各产生G枚固定金音符，6秒批次后结束。Solo冻结全部常规计时器的进度，恢复后继续；Solo专用间隔不受高潮加速。
- 常规品质→爵士变调→复制资格→华丽升品→计分。复制保留复制资格时的品质及升降标记，不继承随后原音符的华丽升品；追加不再变调、复制或触发爵士伴奏。
- H01每个来源每个常规批次最多2枚；H02可作用于追加。每阶段选最高成功率的转换，平率按来源ID；复制平率再优先得分系数。
- 每秒边界先完成常规与派生，然后执行踩镲补拍、木琴下一秒增益，最后重置窗口计数。窗口末追加归当秒，不反复执行窗口效果。
- H03第四批先确定原始品质，不计入后续“实际变色”。升后再降等有实际转换的音符依然保留变色与升降标记。
- A开场计算，不提前取整；布局百分比相加。音符百分比相加，固定分放在百分比后；只对最终S取整，不硬截断0.8～1.6参考区间。

上述边界补全用于获得可复现结果，可在体验后调整。满级重复目前只提示已满级，不擅自增加兑换资源。

## 数据与维护

- `data.json`：唯一发布数值源头，45件`base`和`effect`各6个值；`rules`为概率、时间及资源规则，`presets`为参考坐标。
- `data.js`：供无构建静态页面加载，由同步脚本生成。
- `爱乐之城-五流派数值配置.xlsx`：可在页面导入的六级数值表；参数以JSON值编辑。旧31件Excel不兼容。
- `note-engine.js`：45件效果与事件时钟；`core.js`：复用的摆放、解锁、资源与种子基础工具。
- `app.js` / `styles.css` / `index.html`：交互与展示。
- `verify.cjs`：机制、边界、可复现与资源回归。

修改`data.json`后运行：

```sh
node scripts/sync-data.cjs
node verify.cjs
python -m http.server 4197 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4197/`。页面改值保存在本机，优先于新下载的默认配置；更新版本后，可导入新数值Excel覆盖旧本机配置。存档导出包含参数和布局；发布团队改值时，先把存档中的data保存为data.json，再执行同步与验证。修改机制必须一起修改测试；不得只改描述。

同一ID的旧31件含义不同，本版拒绝旧配置，不迁移旧存档。localStorage使用独立`music-notes-0927-*`前缀。

本项目纯静态，无登录账号、密钥或服务器依赖。任何成员可复制到自己的Git仓库并以根目录开启GitHub Pages，也可部署到其他静态托管。不要提交原始策划总表、账号凭据、本机存档或测试截图。

## 随机扩格更新

达到扩格消耗门槛立即自动解锁。逐格从所有合法的上下左右相邻未开放格中等概率抽取，开启后重新计算候选集合，直到本次额度用完或49格全开。随机扩格使用独立的种子序列，不干扰抽奖与表演随机序列。

初始为中央2行×3列（6格）。已有存档保留当前开放区域；旧版未使用扩格额度会在加载时自动随机兑现。新开或重置模式才使用新的初始6格。自由验证保留标明“测试格数”的调试入口，成长体验没有选格入口。

初始区域方向已更正为2行3列。尚未开始且道具可适配新区域的旧6格开局，刷新后自动更正；已有扩格进度保留，可重置测试新开局。
